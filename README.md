# Lista 03 - UDWMJ

Projeto da disciplina de Desenvolvimento Web com exercícios em HTML, CSS e JavaScript.

## Exercícios

### Exercício 04 — Área do círculo
Arquivos:
- `pratica03exercicio04.html`
- `pratica03exercicio04.css`
- `pratica03exercicio04.js`

O usuário informa o raio e o programa calcula a área usando:

`A = π × raio²`

O valor de π é obtido com `Math.PI`.

### Exercício 05 — Volume da esfera
Arquivos:
- `pratica03exercicio05.html`
- `pratica03exercicio05.css`
- `pratica03exercicio05.js`

O usuário informa o raio e o programa calcula o volume usando:

`V = 4 / 3 × π × raio³`

O valor de π é obtido com `Math.PI`.

### Exercício 06 — Juros compostos
Arquivos:
- `pratica03exercicio06.html`
- `pratica03exercicio06.css`
- `pratica03exercicio06.js`

O usuário informa o capital inicial, a taxa de juros e o prazo do investimento. O programa calcula o montante usando:

`M = C × (1 + i)^t`

A taxa informada em porcentagem é convertida para decimal antes do cálculo.

## Como executar

Baixe o repositório e abra os arquivos `.html` em um navegador.
